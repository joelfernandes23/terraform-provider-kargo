# kargo_warehouse (Data Source)

Retrieves information about a Kargo Warehouse.

## Example Usage

```terraform
data "kargo_warehouse" "example" {
  project = "existing-project"
  name    = "app"
}
```

## Freight State

The `freight` attribute contains the Freight identified by `status.last_freight_id`.

## Example Output

```terraform
output "warehouse_last_freight_id" {
  value = data.kargo_warehouse.example.status.last_freight_id
}

output "warehouse_current_freight" {
  value = data.kargo_warehouse.example.freight
}
```
