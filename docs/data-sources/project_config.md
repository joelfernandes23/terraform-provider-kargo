# kargo_project_config (Data Source)

Reads promotion policies, webhook receiver configuration, and generated endpoints for a ProjectConfig. Promotion policies and receivers are returned as normalized JSON in the Kargo API field format.

Webhook endpoint output is sensitive because some receiver types use an unguessable URL as authentication material.

## Example Usage

```terraform
data "kargo_project_config" "example" {
  project = "example-project"
}
```
