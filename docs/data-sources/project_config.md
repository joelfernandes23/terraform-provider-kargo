# kargo_project_config (Data Source)

Use this data source to look up the promotion policies, webhook receivers, and generated webhook endpoints for an existing Kargo project.

Promotion policies and webhook receivers are returned as JSON so they can be decoded with Terraform's `jsondecode` function. Generated webhook endpoints are marked as sensitive because access to a URL may be enough to trigger that webhook.

## Example Usage

```terraform
data "kargo_project_config" "example" {
  project = "example-project"
}
```

### Required

### Read-Only

- `id` (String) Project name used as the data source identifier.
- `promotion_policies` (String) Promotion policies as JSON. Use `jsondecode` to work with individual values.
- `webhook_endpoint` (Attributes List, Sensitive) Webhook addresses generated by Kargo. Terraform marks them as sensitive. (see [below for nested schema](#nestedatt--webhook_endpoint))
- `webhook_receivers` (String) Webhook receivers as JSON. Use `jsondecode` to work with individual values. Secret values are not included.
