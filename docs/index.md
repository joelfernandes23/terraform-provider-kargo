# Kargo Provider

Use the Kargo provider to manage [Kargo](https://docs.kargo.io/) Projects, ProjectConfigs, Warehouses, and Stages.

## Authentication

The provider supports the following authentication methods:

- **Bearer token**
- **Admin password**

Set exactly one of `bearer_token` or `admin_password`.

Provider arguments can also be set with environment variables:

| Provider Attribute         | Environment Variable              |
|---------------------------|-----------------------------------|
| `api_url`                 | `KARGO_API_URL`                   |
| `bearer_token`            | `KARGO_BEARER_TOKEN`              |
| `admin_password`          | `KARGO_ADMIN_PASSWORD`            |
| `insecure_skip_tls_verify`| `KARGO_INSECURE_SKIP_TLS_VERIFY`  |

`insecure_skip_tls_verify` disables TLS certificate verification.

## Example Usage

```terraform
terraform {
  required_providers {
    kargo = {
      source  = "joelfernandes23/kargo"
      version = "~> 0.3"
    }
  }

  required_version = ">= 1.5.0"
}

variable "kargo_bearer_token" {
  type      = string
  sensitive = true
}

provider "kargo" {
  api_url      = "https://kargo.example.com"
  bearer_token = var.kargo_bearer_token
}
```

## Environment Variable Example

The following environment variables configure admin password authentication without provider arguments:

```shell
export KARGO_API_URL="https://localhost:31443"
export KARGO_ADMIN_PASSWORD="admin"
export KARGO_INSECURE_SKIP_TLS_VERIFY="true"
```

```terraform
provider "kargo" {}
```

## Project Resources

ProjectConfigs, Warehouses, and Stages belong to a Project and require its name in the `project` argument.

### Optional

- `admin_password` (String, Sensitive) Admin account password for Kargo API authentication. Can also be set with the KARGO_ADMIN_PASSWORD environment variable.
- `api_url` (String) The URL of the Kargo API. Can also be set with the KARGO_API_URL environment variable.

- `insecure_skip_tls_verify` (Boolean) Skip TLS certificate verification. Defaults to false. Can also be set with the KARGO_INSECURE_SKIP_TLS_VERIFY environment variable.
