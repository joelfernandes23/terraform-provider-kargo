# kargo_warehouse (Resource)

Provides a Kargo Warehouse resource. A Warehouse subscribes to container image, Git, and Helm chart repositories and produces Freight from discovered artifacts.

## Example Usage

```terraform
provider "kargo" {}

resource "kargo_project" "example" {
  name = "example-project"
}

resource "kargo_warehouse" "example" {
  project = kargo_project.example.name
  name    = "app"

  subscription {
    image {
      repo_url               = "ghcr.io/example/app"
      semver_constraint      = "^1.0.0"
      tag_selection_strategy = "SemVer"
      platform               = "linux/amd64"
    }
  }

  subscription {
    git {
      repo_url          = "https://github.com/example/app-config.git"
      branch            = "main"
      semver_constraint = "^1.0.0"
    }
  }

  subscription {
    chart {
      repo_url          = "https://charts.example.com"
      name              = "app"
      semver_constraint = "^1.0.0"
    }
  }
}
```

## Subscription Types

Each `subscription` block must contain exactly one of `image`, `git`, `chart`, or `generic`.

Subscription order is significant.

## Import

Import an existing Warehouse with `project/name`:

```shell
terraform import kargo_warehouse.example example-project/app
```
