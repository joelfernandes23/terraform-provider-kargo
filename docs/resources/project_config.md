# kargo_project_config (Resource)

Use this resource once per Kargo project to control automatic promotions and incoming webhooks.

Kargo checks promotion policies from top to bottom and uses the first match. Put specific stage rules before broader rules. Exact stage names are recommended for production and other sensitive environments.

For a webhook receiver, provide the name of a Secret that already exists in the project. This resource does not read or store the Secret value. Terraform marks generated webhook URLs as sensitive because access to a URL may be enough to trigger that webhook.

## Example Usage

```terraform
resource "kargo_project" "example" {
  name = "example-project"
}

resource "kargo_project_config" "example" {
  project = kargo_project.example.name

  promotion_policy {
    stage_selector {
      name = "dev"
    }
    auto_promotion_enabled = true
  }

  webhook_receiver {
    name        = "github"
    type        = "github"
    secret_name = "github-webhook-secret"
  }
}
```

For a generic receiver, set `generic_actions` to a JSON array describing which Warehouses Kargo should refresh when the webhook is called.

## Import

Import using the Project name:

```shell
terraform import kargo_project_config.example example-project
```
